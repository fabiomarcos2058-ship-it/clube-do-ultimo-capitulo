# Clube do Último Capítulo 📖

Fan-game **não oficial** de visual novel, sem fins lucrativos, inspirado em *Doki Doki Literature Club*.

**Jogue no navegador:** https://fabiomarcos2058-ship-it.github.io/clube-do-ultimo-capitulo/

No celular, dá pra instalar como app pelo menu do navegador ("Adicionar à tela inicial").

## Avisos
- Este projeto **não é afiliado, associado ou endossado pela Team Salvato**. Os arquivos originais de DDLC devem ser obtidos legalmente em ddlc.moe ou na Steam.
- **Contém spoilers de Doki Doki Literature Club.**
- Contém terror psicológico, sustos e luzes piscando. **Não é adequado para menores de idade nem para pessoas facilmente perturbadas.**
- Os personagens de Blue Lock pertencem a Muneyuki Kaneshiro, Yusuke Nomura e Kodansha. As artes usadas pertencem aos seus respectivos artistas.
